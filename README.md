# XpertShield

Demonstração pública sanitizada desenvolvida para o portfólio da **CarolTech**.

## Visão geral
Ferramenta de auditoria e conciliação que compara informações de fontes distintas, identifica divergências e organiza a revisão antes do fechamento financeiro.

## Capacidades
- Importação de planilhas
- Comparação entre fontes
- Detecção de divergências
- Classificação por gravidade
- Relatório de conferência
- Exportação de arquivo revisado

## Privacidade
Este repositório público **não contém dados reais de clientes**. Identificadores, transações, empresas, contatos e valores são fictícios.
